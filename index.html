Votre galerie

Vos médias enregistrés au même endroit. Les carrousels sont déroulés image par image ; touchez une vignette pour ouvrir la visionneuse.

Connectez votre compte Reddit

Connectez-vous avec l’application Reddit que vous avez créée. Vous n’avez pas besoin de saisir le nom de votre compte Reddit.

Important : saisissez l’identifiant client de l’application, pas votre nom d’utilisateur (par exemple « Gryf » ou « AdeptnessOver9235 »).

Vous n’avez pas encore créé d’application ? Ouvrez les préférences des applications Reddit, créez-en une de type installed app, puis copiez son identifiant client (affiché sous son nom). Configurez l’URI de redirection avec cette adresse exacte : . L’identifiant est public ; ne collez pas de secret ici. Le jeton de renouvellement est conservé dans le navigateur de cet appareil pour éviter de vous reconnecter à chaque visite. Déconnectez-vous sur un appareil partagé ; la révocation complète se fait dans les réglages Reddit.

Installation mobile : utilisez « Installer » dans le navigateur si proposé. Sur iPhone/iPad, ouvrez le menu Partager de Safari puis choisissez « Sur l’écran d’accueil ».

En attendant, importer un export Reddit

Choisissez le fichier JSON de vos éléments enregistrés. Le fichier n’est pas envoyé ; il faudra le réimporter après avoir rechargé la page. Les médias restent hébergés par Reddit.

Aucune image ou vidéo trouvée dans les éléments chargés.
Les liens et publications sans média ne sont pas affichés.
